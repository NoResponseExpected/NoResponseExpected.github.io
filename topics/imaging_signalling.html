20 An image is stored with 4 bits per pixel. A brightness enhancement algorithm adds 3 to every pixel value.
(a) State the maximum number of grey levels available with 4 bits per pixel. 1 mark
(b) A pixel has original value 14. Explain what happens when 3 is added to this pixel value, with reference to the bit depth. 2 marks
(c) Explain why increasing the number of bits per pixel allows the brightness of an image to be varied more smoothly and with less information loss. 3 marks
6 marks ▼ show mark scheme
(a)1 mark
\(N = 2^4 = 16 \text{ levels (values 0–15)}\)
✓16 grey levels
(b)2 marks
✓14 + 3 = 17, which exceeds the maximum value of 15 (with 4 bits, values only go from 0 to 15)
✓The pixel is clipped to the maximum value of 15 — information is lost and the pixel appears at the same brightness as value 13, 14 or 15 (saturation)
(c)3 marks
✓More bits → more possible grey levels (e.g. 8 bits gives 256, 16 bits gives 65,536)
✓Each step in brightness corresponds to a smaller change in intensity → smoother gradations visible
✓With more levels available, adding a fixed brightness value is less likely to push pixel values beyond the maximum — less clipping/saturation so less information loss
